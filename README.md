### 🔗 Snip URL — Distributed URL Shortener
> [Live Demo](https://snipurl-itsmeet.vercel.app/)

Production-style URL shortener built around real distributed systems concepts.

- **Horizontal DB sharding** (hash-based) + **primary–replica read/write separation**
- **Redis cache-aside** with LFU eviction and TTL-based key management
- **Snowflake ID generation** for distributed uniqueness
- **Redis token bucket rate limiter** + NGINX load balancing; containerized with Docker + Flyway

`Java` • `Spring Boot` • `PostgreSQL` • `Redis` • `Docker` • `NGINX` • `React`
